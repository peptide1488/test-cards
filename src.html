Saved templates

Templates are saved in this browser. To send one to the admin: Save + download .json (or ⬇ on a saved one) and send that file - the admin forwards it to the Telegram bot, then /use name. Use Export to back them up or send them to someone (Import loads them back). A template file in the tool's presets folder can be used by the Telegram bot with a Layout: name line.

Click anything on the card, then drag a corner handle to resize it. Transparent parts of the hero are click-through, so you can grab the moon behind it; Alt+click cycles through stacked elements; arrow keys nudge the selected element (Shift = 10px). You can also drop a hero image straight onto the card. Drag any element on the card to move it. Every element can be hidden, moved, resized and recoloured below.
